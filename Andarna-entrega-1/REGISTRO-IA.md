# Projeto Integrador - Andarna (Entrega 1)

Repositório da Entrega 1 (Esqueleto Semântico) do Projeto Integrador de Sistemas de Informação.

## Sobre o Projeto
Construímos a estrutura base de 4 páginas em HTML puro para a plataforma de catálogo de livros **Andarna**, focando em:
- Estruturação semântica com landmarks (`header`, `nav`, `main`, `section`, `aside`, `footer`).
- Hierarquia lógica de cabeçalhos (`h1`, `h2`, `h3`) única por página e sem saltos.
- Navegação interna coerente e checklist de acessibilidade aplicado.

## Registro de Uso de IA
Utilizamos ferramentas de IA apenas no final para conferir e validar o nosso código, garantindo que os elementos de acessibilidade (como o atributo `lang="pt-BR"`, o *skip link* e a navegação por teclado via tecla Tab) estavam corretos de acordo com as exigências da disciplina.

# Projeto Integrador - Andarna (Entrega 2)

Repositório da Entrega 2 (Estilo e Responsividade) do Projeto Integrador de Sistemas de Informação.

## Sobre o Projeto
Desenvolvemos a folha de estilos em CSS próprio para a plataforma **Andarna**, focando em:
- Estruturação de layout moderno utilizando Flexbox e CSS Grid, sem utilização de frameworks externos.
- Adaptação visual responsiva para atender aos 3 breakpoints obrigatórios (mobile, tablet e desktop).
- Garantia de contraste adequado e integridade visual em todas as larguras de tela.

## Registro de Uso de IA
Utilizamos ferramentas de IA apenas no final para conferir a sintaxe, validar o comportamento dos breakpoints e revisar a aplicação das variáveis CSS, garantindo que o código estivesse alinhado com as exigências de entrega.
